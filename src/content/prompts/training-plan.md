title: Training plan outline
order: 3
summary: When to start building, and the phases between now and your goal.
useWhen: At the start of a season or a new goal, after your debrief.
examples:
  - "Cycling: test FTP first."
  - "Swimming: test a CSS set first."
  - "Golf: track strokes gained or a practice-round baseline first."
---
Using my profile and history, propose when my next training block should start and lay out the plan to [goal] in phases (for example base, build, sharpen, taper). For each phase give the purpose, rough weekly hours, and the one or two key sessions that matter most. Tell me what you'd want to test or measure first so we have a baseline, and why.
